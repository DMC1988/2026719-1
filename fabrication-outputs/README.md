# fabrication-outputs/

Un subdirectorio por cada revisión fabricada: `revA/`, `revB/`, etc. Cada uno debe contener el snapshot exacto de Gerbers, Drill, BOM y Pick&Place tal como se envió al fabricante en ese momento. Nunca se sobreescribe una carpeta de rev ya existente — una vez fabricada, es historia inmutable (igual que el tag de Git correspondiente).
